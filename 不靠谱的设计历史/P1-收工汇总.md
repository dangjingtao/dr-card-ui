## 3. 关键设计决策

### 3.1 Design Library token 体系
- 颜色:全部用 `--com-neutral-*` / `--com-warm-*` / `--com-brand-*` / `--com-premium-*` / `--com-success-*` / `--com-danger-*`,无散落 hex。
- 消费者命名:用 `--color-primary/primary-hover/disabled/on-primary/text-*/background/surface/border-*/success/danger`。
- 排版:用 `--type-body/caption/label/label-small/body-small/heading-small/title/display` + `--font-family-base`,不写裸 px 字号。
- 间距:用 `--com-space-*`(4 步进)。
- 圆角:用 `--radius-xs/sm/md/lg/pill`。
- 尺寸:用 `--com-size-32/40/44/48/56`,所有可点击元素 ≥ 44pt。
- 阴影 / 动效:沿用 `me-ambient` 暖金光斑 + 600ms 渐入。

### 3.2 私有 token(经 P1 总调度 §4 异常处理豁免)
- T11 / T13 在 `:root` 内联 CSS 变量登记 banner 渐变 + 光斑色(`--t11-banner-*` / `--t13-banner-*`),原因:深绿主色 + 暖金光斑是任务卡强约束的设计语言,无既有 token 直接对应。
- 全部硬编码值已在各 `check.json` 的 `hardcoded_values` 字段逐条列明,便于后续 P2 抽离到 Design Library。

### 3.3 `--com-premium-500` 取值
- `colors_and_type.css` 中实际值为 `#A07B41`(深金棕),与公共头描述的 `#F59E0B` 不一致。
- 处理:沿用 design-tokens 实际值(与 T10 范式一致),**不再硬编码覆盖**,避免双源冲突。

## 4. A11y / 触控一致性

- `:focus-visible`:2pt `--com-brand-500` / `--com-premium-500` outline + 2–4pt offset。
- 按钮:全部带 `aria-label`,主 CTA 文字 ≥ 18pt。
- Tab:`role="tab" aria-selected aria-controls`。
- 进度条:`role="progressbar" aria-valuenow aria-valuemin aria-valuemax aria-label`(T14)。
- Toast:`role="status" aria-live="polite"`(T12)。
- 命中区:输入框 56、商品卡 167.5+、头像 64×64、主按钮 48。
