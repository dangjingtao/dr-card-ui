# 交付说明：首页 / 泡泡页 → Figma

本目录是给**外部原生端（iOS / Android / 小程序）**做实现参照用的设计交付。
视觉事实源是当前 dr-card-ui 的 React 实现，不是历史摹客原型。

---

## 一、我不能直接给 .fig 的原因

`.fig` 是 Figma 的私有二进制格式，没有公开写入规范，官方也不提供离线生成 `.fig` 的接口。
任何声称"本地直接生成 .fig"的做法都是逆向猜测格式，产物随 Figma 版本更新即损坏，不能作为工程交付。

**唯一可靠的路径是：在 Figma 里生成图层，再由你另存为 `.fig`。**
下面两条路都能得到真图层（文本可选中、图标是矢量、间距可量），差别只在保真度。

---

## 二、路线 A（推荐）：插件导入，保真最高

**能拿到而路线 B 拿不到的东西：**

- **阴影 92 处**（首页 61 / 泡泡页 31）→ 还原为 Figma 原生 Effect，不是栅格图
- **颜色变量 57 个** → 自动建 `dr-card-ui` 变量集合，填充直接绑定 Variable
- 图片以真实 Image Fill 写入，而不是 base64 贴图

### 操作步骤

1. 打开 Figma 桌面版（浏览器版不支持加载本地插件）
2. 菜单 `Plugins` → `Development` → `Import plugin from manifest...`
3. 选择本目录下 `figma-plugin/manifest.json`
4. 新建一个设计文件，运行插件 `DR Card UI → Figma`
5. 在插件面板里选中 `home.json` 和 `points.json`（可多选），点「导入」
6. 导入完成后 `File` → `Save as .fig` 或直接存到你的 Figma 团队空间

两个画板会横向排开，均为 375 × 812。

---

## 三、路线 B：拖 SVG，零安装

把 `home.svg` / `points.svg` 直接拖进 Figma 画布即可，Figma 会自动拆成 Frame / 矢量 / 文本。

**代价：**

- 阴影全部缺失（92 处），层次会偏平，需要导入后手工补 Effect
- 颜色是散装 hex，不绑定 Variable

赶时间看版式可以走这条；要交给原生端长期对照，建议走路线 A。

---

## 四、当前质量实测

| 指标 | 首页 | 泡泡页 |
|---|---|---|
| 画板尺寸 | 375 × 812 | 375 × 812 |
| 图层总数 | 263 | 159 |
| 文本图层 | 93 | 55 |
| 图片 | 6 | 3 |
| 阴影（仅路线 A 保留） | 61 | 31 |
| 与 React 像素差异 | 10.14% | 7.81% |
| Token 覆盖率 | 76% | 57% |

像素差异的主要构成是阴影缺失（仅路线 B）与 CJK 文本基线 1–2px 漂移。

---

## 五、已知限制

1. **Token 覆盖率未达标**：裸值里混有 Tailwind 默认色杂质（`gray-200`、`slate-500`、`amber-500`），另有一批金色中间调未进 `--premium-*` 阶梯。原生端目前量到的会是散装 hex，而非语义变量名。
2. **CJK 文本基线**为 0.8 近似，可能有 1–2px 垂直漂移。
3. **不含 Auto Layout**：IR 采用绝对定位重建，保真优先。原生端可正常量取间距，但图层不会随内容自适应。
4. 目前只覆盖 2 屏。全量为 160 屏（41 路由 + 108 状态 + 13 弹层，据 `src/app/router/routes.ts` 统计）。
