## 2. 诗得丽品牌专栏首页

### 2.1 页面定位调整

原 APP 首页改为新的「诗得丽品牌专栏」首页，不再保留当前首页的金刚区结构。

名称口径：本轮按用户此前明确确认的「诗得丽品牌专栏」记录。后续沟通中曾出现一次「诗得力品牌专栏」写法，当前按输入笔误处理；若产品名称实际变更，需单独修正文案。

### 2.2 页面结构

页面从上到下依次为：

1. 页面标题「诗得丽品牌专栏」。
2. 顶部搜索栏与头像，保持现有样式和位置。
3. 现有 Banner，继续保留。
4. 删除现有金刚区，不保留淋浴、洗烘、饮水、吹风等入口。
5. Banner 下方迁入 `/checkin` 的全部打卡业务内容。
6. 打卡内容结束后依次展示「公益板块」与「卡博士品牌故事」。
7. 底部导航保持现有固定方式。

### 2.3 打卡内容迁入规则

- 暂时完整迁入 `/checkin` 的内容、状态和主要操作。
- 不重复迁入 `/checkin` 自己的页面标题、返回按钮和底部导航，避免首页出现两套页面外壳。
- 公益板块和品牌故事位于打卡模块下方，随页面内容正常滚动，不做吸底或悬浮。

## 3. 新用户体验券弹窗

### 3.1 触发与展示

- 面向新用户，在「诗得丽品牌专栏」首页弹出。
- 交互和视觉可参考 `/dearseed?overlay=reminder` 的现有弹窗形式。
- 每次展示时，在前端演示状态中随机呈现 1 张或 2 张体验券。
- 弹窗内需要直接展示本次赠送的体验券商品内容和数量。

### 3.2 操作结果

- 点击确定：先呈现领取成功反馈，再跳转到体验券页面。
- 点击关闭：关闭弹窗，不领取，停留在首页 `/`。
- 本阶段仅实现 UI 演示状态，不接真实新用户识别、领券或库存接口。

## 4. 泡泡值页面调整

### 4.1 新增纯明细页

新增独立的泡泡值明细页面，页面内容仅包括：

- Tab：全部 / 收入 / 消耗；
- 泡泡值流水列表；
- 对应筛选状态和已有空态。

Tab 与流水列表可以继承当前泡泡值明细页面的现有样式。

### 4.2 原页面改造

- 当前泡泡值页面不再以流水列表作为主要内容。
- 将原明细区域释放出来，改为任务内容区。
- 任务内容先使用视觉完整、符合现有金橙体系的任务占位卡片。
- 可参考现有任务语义展示每日打卡、连续签到、观看视频、邀请好友等占位内容，但不新增真实任务业务逻辑。
- 顶部资产区域中的「看明细」跳转到新增的纯泡泡值明细页。

### 4.3 泡泡福利入口

「泡泡福利」区域调整为三个入口，顺序为：

1. 每日签到；
2. 澡运；
3. 体验券兑换。

澡运入口保持当前金色插画卡片风格。澡运入口及目标页面本阶段均先做占位，不补充未确认的抽签规则。

### 4.4 兑换按钮文案

泡泡值页面底部主按钮文案由「立即兑换」改为「泡泡值兑换」。按钮样式、位置及原跳转逻辑保持不变。

## 5. 体验券使用弹窗

### 5.1 删除文案
