## 1. 素材目录规范（目标约定）

页面施工落位后，品牌素材统一收敛到 `src/assets/brand/`，按语义分子目录：

```text
src/assets/brand/
├── member/     # 会员卡、会员等级
├── bubble/     # 泡泡值、签到卡
├── coupon/     # 卡券、核销、分享
├── luck/       # 今日澡运、抽取成功
├── buddy/      # 搭子、邀请
├── exchange/   # 洗护兑换、商城商品
├── support/    # 客服、福利官
└── ip/         # 品牌 IP（白熊等，需授权确认）
```

命名规则：`<语义>-<场景>-<@2x 后缀>`，运行物料统一使用 `.webp`，如 `member-card-dark.webp`、`luck-draw-result.webp`。

运行资产硬规则：`src/assets/` 内的位图必须为 WebP，单文件不得超过 500 KiB；`npm run verify:images` 与正式构建会强制检查。原型源文件、历史证据和验收截图可保留原始 PNG/JPG，不属于运行物料。
每个素材在 `src/assets/brand/MANIFEST.md` 登记：源文件、原型节点、用途、裁切、授权状态。

> 当前阶段（页面尚未施工）素材仍保留在 `mockplus/卡博士诗得丽/data/` 与 `assets/`，本清单给出**源定位**，
> 防止施工时误用低清截图或重新造图。
