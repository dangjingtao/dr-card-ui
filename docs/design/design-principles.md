# 卡博士 APP UI 设计原则

## 1. 原型真实性原则

卡博士不是重新设计项目，而是将已确认产品原型转化为可运行 UI。

视觉依据优先级：

1. 已确认 Mockplus 原型
2. 当前设计说明
3. Com Design 规范
4. 优化建议

任何优化不得破坏原有产品意图。

## 2. 移动优先原则

卡博士是移动 APP。

设计优先考虑：

- 单手操作
- 触控区域
- 信息层级
- 页面节奏
- 移动端阅读体验

避免后台化、桌面化布局。

## 3. Com Design 一致性原则

卡博士使用 Com Design 作为基础设计体系。

组件层级：

Com Design Core
→ Mobile Extension
→ Card Business Components
→ Pages

组件应复用和沉淀，不在页面临时创造。

## 4. 土豪金品牌语义原则

颜色承担产品语义。

Gold：

- 会员身份
- 权益价值
- 奖励
- 高价值内容

Orange：

- 行动入口
- CTA
- 转化操作

禁止全页面堆叠金色，避免视觉廉价化。

## 5. 卡片化信息原则

卡博士核心对象是卡与权益。

卡片需要表达：

- 身份
- 价值
- 状态
- 操作

不同卡片类型需要形成明确业务语义。

## 6. 年轻可信原则

视觉方向：

年轻 + 活力 + 商业可信。

避免：

- 传统金融产品的沉闷
- 游戏充值产品的夸张
- 电商促销页面的噪声

## 7. 状态完整原则

高保真 UI 不只包含正常状态。

需要考虑：

- 空状态
- 加载状态
- 错误状态
- 禁用状态
- 成功反馈

## 8. AI 协作原则

智能体修改设计时必须说明：

- 修改依据
- 影响范围
- 是否改变设计意图

遇到不明确设计，不自行决策，应提出讨论。
