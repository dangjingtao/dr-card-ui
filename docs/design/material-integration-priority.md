## 1. 结论

展示优先级建议按下面顺序推进：

1. **P0：今日澡运主插画**——当前首屏中心是通用圆形图标，视觉空洞最大；Penpot 有可单独导出的主插画组，且不必改业务文案。
2. **P0：我的页热门兑换商品图**——当前 4 张商品卡仍是纯色文字占位；Penpot 有 4 张一一对应的红 / 黄 / 蓝 / 绿商品图，替换成本低、首屏增益直接。
3. **P1：兑换专区商品图与 Banner**——展示收益高，但 Penpot 图片内的 SKU、价格和现有页面夹具不一致；确认商品映射前不能直接接入。
4. **P1：卡包已使用空态插画**——能改善二级状态，但曝光低于主入口，排在核心页面之后。
5. **暂缓：澡运结果、通知详情、签到福利**——Penpot 视觉里带有当前未确认的业务表达或与现有事实源冲突，不能当作单纯物料替换。

其余页面已有合适品牌素材，或没有明确适配的 Penpot 物料；本轮不为“补图”而补图。

## 3. 明确暂缓项

| 路由 / 模块 | 暂缓原因 |
| --- | --- |
| `/luck/result` | Penpot 结果页包含“大吉 / 换一签 / 好运值”等表达；当前代码明确隔离了三档签运与重抽规则（B-003），不能以补物料的名义带入未确认规则。 |
| `/notifications/:id` | Penpot 图片对应“卡券到期提醒”，当前消息夹具没有同标题通知；直接接入会造成图文事实不一致。 |
| `/checkin` | Penpot 的“每日签到福利”偏 7 天福利展示，当前事实源是月历式打卡；只截取金币也未必与现有奖励规则匹配。 |
| `/membership` | Penpot 有墨绿会员卡图，但当前已使用高清 `member-lv4-hero.webp`，首屏展示已成立；替换增益有限，不优先。 |
| `/home`、`/settings`、`/brand-culture`、搭子相关页 | 已接入头像、Banner、会员活动、品牌长页或搭子 IP 等现成素材，无明显展示缺口。 |
| 订单、地址、客服、核销等功能页 | Penpot 未发现能稳定映射且明显提升展示的独立物料；保持功能型界面，不勉强装饰。 |

## 4. 确认口径

建议用户只确认下面三件事即可开工：

1. 是否先接 **A1 今日澡运主插画 + A2 我的页 4 张商品图**。
2. 兑换专区是否允许采用 Penpot 的商品视觉；若允许，商品名称 / 价格以 **现有夹具** 还是 **Penpot 图内信息** 为准。
3. 是否允许兑换专区新增 Penpot Banner；若只补物料、不改信息结构，则 B2 跳过。

## 5. 接入时的验收边界

- 物料落到 `src/assets/brand/<domain>/`，登记来源、Penpot shape ID、用途与裁切方式。
- 优先导出独立图片填充；矢量组合只导出明确命名的主插画组，不把整张页面截图当素材。
- 保留现有路由、文案、状态和交互；任何业务规则变化另行确认。
- 以 375 × 812 截图对比接入前后，检查裁切、清晰度、重复文案和首屏信息层级。
- 没有合适物料或映射不确定时，保持现状。
