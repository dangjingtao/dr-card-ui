完成会员资产查看、每日打卡/补签和今日澡运三条互相可达的会员玩法链路。

## 实施要求

- 会员中心表达等级、权益、泡泡值、打卡、澡运和去向入口。
- 会员等级使用原型确认的等级数量和品牌卡面，不凭历史文档扩级。
- 打卡日历覆盖已打卡、今天、可补签、不可补签及月份切换规则。
- 泡泡值流水区分收入/支出并保留原型文案差异，不私自统一为积分。
- 抽签状态由确定性 fixture 驱动，验收期间不可随机漂移。

## 状态与交互矩阵

- 会员等级当前/未解锁/最高级。
- 泡泡值有记录/空态、收入/支出。
- 打卡提醒/成功/已打卡、可补签/补签成功/余额不足或不可补签。
- 今日澡运未抽/抽取中/抽取成功/重复进入。

## 验收标准

- 9 个节点逐一可定位。
- 打卡和澡运主链路可连续操作并保持一致状态。
- 删除或隔离所有未确认的随机三档与重抽规则，直到有决策记录。
- 会员卡、等级和 IP 视觉有原型对照，不以通用圆形渐变代替。
