## 1. 决策目的

按 `AGENTS.md` 第 5、6、9 条和 `task-ledger.md` 第 5 节，对 12 个非本轮实施节点逐一形成范围结论，防止：

- 智能体因“全量还原”自行施工暂缓/试验页面；
- “全量页面适配整理”把暂缓节点偷渡进实现任务；
- 删除 Mockplus 离线包、`不靠谱的设计历史/` 或说明文档中的证据；
- 路由误暴露暂缓功能，破坏用户旅程的可达性约束。

## 2. 标记体系

每个节点被标记为以下状态之一：

| 状态 | 含义 |
| --- | --- |
| `Exclude` | 当前不施工；不进入 T005–T013。 |
| `Preserve Evidence` | 保留 Mockplus / 历史稿 / 说明文档作为证据；不删除、不施工。 |
| `Future` | 暂缓但保留未来重新评估的入口；不得从历史稿反推产品规则。 |
| `Superseded` | 被当前主线（泡泡值/会员/搭子等）替代的旧稿表达，不与主线并存。 |
| `Needs Decision` | 暂缓范围之外仍需要用户/产品确认是否转入实施。 |

### 3.1 决策理由摘要

- **`#1`**：摹客页面树中“首页”实为约 60 个业务画板集中摆放的总览画布，不应被理解为单页信息架构，因此排除为业务实现，仅保留证据。
- **`#3`**：颜色测试是设计验证页，不承载业务旅程，路由不得对外暴露。
- **`#9/#52/#53`**：健康管理及其子页“数据填写 / AI 推荐”在原型中已标注“暂时不做”，本项目未涉及健康数据采集与 AI 推荐业务。
- **`#10/#45/#46/#47`**：数字空间及其子页“单品碎片 / 获取碎片”在原型中已标注“暂时不做”，且涉及数字藏品业务与合规，暂缓。
- **`#31`**：搭子默契值在原型中标注“先不做”；历史 T14 自补的 4 维评分、7 天曲线、双头像、48px 总分都不是产品事实，必须在恢复前与用户重新讨论。
- **`#50/#51`**：卡博士积分界面与积分明细是旧/并存的积分体系，与当前主线的“泡泡值”并存；按 `AGENTS.md` 第 6 条，禁止擅自统一两套资产体系。

## 4. 路由 / 入口审计

审计对象：`src/app/router/index.tsx`、`src/components/mobile/BottomNav.tsx`、`src/layouts/MobileLayout.tsx`、`src/pages/*`、`src/components/**`。

### 4.1 当前路由清单

| 路径 | 节点 / 用途 | 状态 | 命中暂缓节点？ |
| --- | --- | --- | --- |
| `/` | Home（诗得丽专栏骨架，T005） | Doing | 否 |

| `/draw-success` | DrawSuccess（今日澡运结果，T006，待确认 T03） | Doing | 否 |

### 4.2 底部导航与全局入口

`BottomNav.tsx` 仅有 4 个 Tab：首页 `/`、卡包 `/card`、兑换 `/exchange`、我的 `/profile`。这 4 个 Tab 与 12 个暂缓节点均无对应关系。

`MobileLayout` 仅承载 `<Outlet />` 与 `<BottomNav />`，不暴露暂缓页面。

### 4.3 链接扫描

对 `src/` 全量 `Link / to= / href=` 扫描：

- `BottomNav` 中 `navigate(value)` 仅跳到上述 4 个 Tab。
- 其余页面与组件未使用 `Link` 或 `href`，未在客户端产生暂缓节点的可点击入口。
- 无 `react-router-dom` 的 `<Link to=...>` 命中 12 个暂缓节点对应路径。

### 4.4 审计结论

- 12 个暂缓节点在当前代码中**均无独立路由**、**无导航入口**、**无页面级可达路径**。
- 12 节点与 60 实施节点的路由命名空间互不重叠，不会因为新增业务路由而被误暴露。
- `draw-success` 不是暂缓节点（属于 T006 / 待确认 T03），但其内置的“大吉/中吉/小吉、随机重抽、再抽一次”规则未在原型中明确确认，本卡不替 T006 决策，但记录此风险给 T006。
