# 卡博士诗得丽 UI 改造任务评估

## 评估结论

本项目不是 Mockplus 页面机械还原，而是：

> 原型业务结构保留 + Com Design 体系重构 + 卡博士品牌视觉升级。

设计源：Mockplus「卡博士诗得丽」v3。

- 原型规模：72 个页面 / 60 个 artboard
- 基准：375 × 812 pt
- 原型优先，文档为辅助说明

## 设计约束

### 上限

由 Mockplus 原型提供：

- 信息架构
- 页面流程
- 品牌资产
- 白熊 IP
- 会员体系
- 泡泡值、卡包、兑换等业务语义

### 下限

`不靠谱的设计历史` 作为视觉质量下限：

- 新页面不得低于历史设计质量
- 风格不得大幅偏移
- 不重新创造另一个产品视觉

### 设计体系

Com Design 负责：

- Token
- 基础组件
- 通用交互

卡博士品牌层负责：

- 金色会员卡
- IP 卡片
- 泡泡值组件
- 兑换组件
- 活动视觉

## 任务拆解原则

不超过 15 张任务卡。

按照：

基础 → 组件 → 核心页面 → 扩展页面 → 验收

拆解。

## 验收原则

- 不低于《不靠谱的设计历史》质量线
- 保持卡博士品牌连续性
- 使用 Com Design 组件体系
- 页面可运行
- Build 通过
