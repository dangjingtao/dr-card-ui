## 背景

卡博士 APP 除了淋浴、洗烘、饮水、吹风四类服务设备外，还新增了**自助售货机**场景。用户通过 APP 扫描自助售货机二维码后，进入专属购买页面，使用账户余额购买商品（首期为洗发水体验包）。

## 目标

- 用户扫码自助售货机后，进入**扫码购买页**（区别于设备启动页）
- 支持商品选择（规格/数量）+ 余额支付 + 购买成功反馈
- 与现有设备体系、账户余额体系打通

## 交互流程

```
设备列表（售货机分类）
     │
     ▼  点「扫码购买」按钮
  扫码确认 BottomSheet
     │
     ▼  确认扫码
 /vending/buy?id=xxx（扫码购买页）
     │
     ├─ 顶部：设备位置 + 设备编号
     ├─ 商品图占位 + 商品名 + 价格（划线原价）
     ├─ 规格选择（单选卡片）
     ├─ 数量选择（- / 数字 / +）
     └─ 底部结算栏：余额显示 + 合计 + 「立即购买」按钮
           │
           ▼  点击「立即购买」
        支付中（按钮 loading，1.2s）
           │
           ▼  扣减余额
        购买成功弹窗（绿色对勾 + 商品明细 + 「完成」按钮）
           │
           ▼  点「完成」
        返回上一页
```

## 验收标准（MVP）

1. 从设备列表页选「售货」分类，点卡片上「扫码购买」→ 确认 → 进入购买页
2. 购买页显示设备名称、编号、商品信息、价格
3. 可切换规格（单包 / 三连包），价格随之变化
4. 可增减数量（1~99），合计实时计算
5. 点「立即购买」→ 按钮显示"支付中" → 1.2s 后弹购买成功弹窗 → 扣减余额
6. 余额不足时按钮禁用，显示"余额不足，请先充值"
7. 购买成功弹窗显示商品明细，点「完成」返回上一页
