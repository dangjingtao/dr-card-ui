> 任务卡编号：**T042**

## 背景

卡博士 APP 除了淋浴、洗烘、饮水、吹风四类服务设备外，还新增了**自助售货机**场景。用户通过 APP 扫描自助售货机二维码后，进入专属购买页面，使用微信/支付宝支付购买洗发水体验包（首期 3 款），支持优惠券自动抵扣。

## 目标

- 用户扫码自助售货机后，进入**扫码购买页**（区别于设备启动页）
- 支持 3 款洗发水体验包选择（去屑 / 控油 / 虫草修复）+ 数量调节
- 优惠券自动优先抵扣（强制），1 张券抵 1 包（¥1）
- 支付方式（微信 / 支付宝）直接放在购买页底部，不再单独成页
- 支付成功后：出货中（3s 倒计时）→ 出货成功弹窗
- 首页"扫一扫"增加演示入口（4 类设备 + 洗发水），便于直接体验

## 交互流程

```
首页扫一扫 / 设备列表 → 扫码
         │
         ▼
  /vending/buy（扫码购买页）
         │
         ├─ TitleBar：< 返回 + 扫码购买（返回 → /legacy-home）
         ├─ 顶部渐变区：设备位置 + 设备编号 + 标题「洗发水体验装」
         ├─ 3 款洗发水（卡片 + 渐变图标 + 名称 + 描述 + ¥1 + 数量加减）
         ├─ 优惠券区（可用张数徽标 + 已抵扣提示 + 抵扣券详情行）
         ├─ 支付方式：微信 / 支付宝（单选卡片）
         └─ 底部结算栏：实付金额 + 确认支付按钮
              │
              ▼  点击支付
          支付中（1.2s）
              │
              ▼
         「正在出货...」弹窗
              │（3s 倒计时）
              ▼
         「出货成功！」弹窗
              │
              ▼  点「完成」
         返回首页
```

## 验收标准（MVP）

1. 首页「扫一扫」→ 2×2 网格显示淋浴/洗烘/饮水/吹风 4 个设备模拟按钮 + 模拟购买洗发水按钮
2. 点淋浴/饮水 → 进入设备启动页（自动启动流程）
3. 点洗烘/吹风 → 进入设备详情页（选金额后手动启动）
4. 点「模拟购买洗发水」→ 进入购买页（TitleBar 显示返回 + 扫码购买）
5. 购买页显示 3 款洗发水，每款可独立增减数量（0~99）
6. 优惠券自动抵扣 ¥1（1 张券），实付金额实时更新
7. 数量为 0 时「确认支付」按钮禁用
8. 支付方式可切换微信 / 支付宝
9. 点「确认支付」→ 支付中 → 出货中弹窗（3s 倒计时）→ 出货成功弹窗
10. 点 TitleBar 返回按钮 / 出货成功点「完成」→ 返回卡博士APP首页
11. 扫码页所有元素不超出页面高度，浏览器拉宽时页面居中不拉伸（max-w 430px）
