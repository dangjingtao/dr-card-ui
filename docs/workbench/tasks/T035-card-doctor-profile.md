# T035｜卡博士个人中心

## 状态与类型

- 状态：`Draft`
- 类型：UI / Profile / Account
- 优先级：P0

## 当前事实与差距

- 卡博士APP底部导航「我的」Tab 当前无实际页面，仅视觉展示（`LEGACY_TAB_ITEMS` 中 `profile` 项无 `to`）。
- 现有 `/profile` 页（T011，已验收）是诗得丽会员体系的「我的」页，包含：会员 hero（头像/昵称/VIP/等级进度/三宫格）、6 宫格常用功能、热门兑换。
- 卡博士APP的个人中心与诗得丽会员中心是否共用同一页面待确认。两者可能在品牌调性、功能入口、资产展示上有差异。
- T026（注册登录与个人信息）已存在，覆盖注册登录流程和个人信息编辑，但个人中心主页本身的卡博士语境未明确。
- T029（APP 充值功能）已存在，充值入口应放在个人中心。
- 首页头像当前跳 `/membership`（会员中心），在卡博士APP语境下应跳个人中心。

## 目标

1. 建立卡博士APP的「我的」Tab 个人中心页面。
2. 明确卡博士个人中心与诗得丽会员中心的关系：共用还是独立。
3. 整合卡博士APP相关功能入口：订单、卡包、地址、充值、设置等。
4. 与 T026（注册登录）、T029（充值）、T010（地址/订单）等功能卡衔接。

## 原型范围

- 需求来源：现有 `/profile` 页结构（参考）+ 「不靠谱的设计历史」中个人中心参考稿（仅作参考，不直接照搬）+ 卡博士APP功能清单。
- 页面区块（待确认）：
  - 用户信息区：头像、昵称、会员等级（卡博士体系）
  - 资产区：泡泡值、卡券、积分（待确认）
  - 订单入口：全部订单 / 进行中 / 待评价
  - 常用功能：地址管理、卡包、兑换码、客服中心、设置
  - 充值入口（与 T029 衔接）
  - 诗得丽品牌专栏入口（跳转到诗得丽专栏）

## 不在范围

- 不做注册登录流程（由 T026 覆盖）。
- 不做充值功能实现（由 T029 覆盖，本页仅提供入口）。
- 不做个人信息编辑（由 T026 / 现有 `/settings` 覆盖）。
- 不接真实用户数据（使用夹具数据）。

## 实施要求

- 个人中心为一级 Tab 页，显示三项底部导航（首页 / 服务 / 我的）。
- 页面顶部显示用户信息（头像、昵称、等级等），点击可进入个人信息编辑（`/settings` 或 T026 指定页面）。
- 资产区展示用户核心资产（泡泡值、卡券数量等），点击可进入详情。
- 订单区提供订单管理入口，跳 `/orders`（现有页面）。
- 常用功能区以宫格或列表形式展示，点击跳转到对应功能页。
- 提供充值入口，跳 T029 指定的充值页。
- 提供诗得丽品牌专栏入口，跳 `/dearseed`。
- 整体风格与卡博士APP保持一致。
- 使用确定性夹具数据。

## 状态与交互矩阵

- 个人中心默认态（全部内容展示）。
- 点击头像/昵称 → 个人信息编辑页（`/settings` 或 T026 页面）。
- 点击泡泡值 → 泡泡值页（`/points`，T006/T022）。
- 点击卡券 → 卡包页（`/card`，T009）。
- 点击订单 → 订单管理（`/orders`，T010）。
- 点击地址管理 → 地址列表（`/address`，T010）。
- 点击充值 → 充值页（T029）。
- 点击客服中心 → 智能客服（`/service/chat`，T013）。
- 点击设置 → 资料设置（`/settings`，T011）。
- 点击诗得丽品牌专栏 → `/dearseed`。
- 底部导航切换：首页 / 服务 / 我的。

## 验收标准

1. 个人中心作为底部 Tab「我的」可正常访问。
2. 用户信息区、资产区、订单区、功能区布局还原正确。
3. 所有功能入口可正常跳转到对应页面。
4. 底部导航高亮正确（我的 Tab 高亮）。
5. 从首页头像进入个人中心路径正确。
6. `npm run typecheck` 和 `npm run build` 通过。
7. 页面直接访问与刷新不白屏。
