# T036｜四大设备功能页面（淋浴/洗烘/饮水/吹风）

## 状态与类型

- 状态：`Done`

- 类型：UI / Feature / Device

- 优先级：P0

## 当前事实与差距

- 四大设备功能（淋浴/洗烘/饮水/吹风）是卡博士APP的核心服务，通过首页四金刚区入口进入。
- 每个设备类型有独立的主题色：淋浴（紫色）、洗烘（青绿）、饮水（蓝色）、吹风（暖黄）。
- 设备动线：首页金刚区 → 设备列表页 → 扫码/点击使用 → 设备详情页（金额选择 → 启动 → 结算）。
- 已完成设备列表页、设备详情页（含启动流程、结算、紧急停止、保修悬浮球）的全部施工。

## 目标

1. 完成淋浴/洗烘/饮水/吹风四类设备的完整页面施工。
2. 统一设备页面的交互模式，通过主题色区分设备类型。
3. 打通首页 → 设备列表 → 设备详情 → 结算的完整动线。

## 原型范围

- 设备列表页（`/device/:type`）：设备图标+名称+位置+编号+状态+扫码按钮。
- 设备详情页（`/device/connecting`）：设备信息、账户余额、金额选择、四步启动状态、确定启动/结算按钮、紧急停止、保修悬浮球。
- 结算弹窗：设备已停止 + 本次消费 + 剩余余额 + 我知道了。
- 紧急停止弹窗：设备已强制停止 + 本次消费 + 剩余余额 + 我知道了。

## 不在范围

- 不实现真实扫码功能（点击扫码按钮直接进入详情页）。
- 不接入真实余额数据（使用 fixture 模拟）。
- 保修页面暂不施工，仅保留悬浮球入口。
- 不实现设备使用中的实时计时/扣费动画。

## 实施要求

- 四种设备共用同一套页面组件，通过 `:type` 参数切换主题色与文案。
- 设备列表页卡片结构：左侧图标 + 中间名称/位置/编号 + 右侧状态/按钮。
- 设备详情页包含：设备信息卡、账户余额、金额选择、启动状态列表（四步）、底部操作按钮、紧急停止、保修悬浮球。
- 启动流程：四步逐步点亮动画，完成后按钮变为"结算"。
- 结算与紧急停止均弹出对应弹窗，点击"我知道了"关闭并扣除余额。
- 所有页面宽度不超过 480px，居中显示。

## 状态与交互矩阵

- 设备列表：空闲态（扫码按钮）/ 使用中（灰色标签）。
- 设备详情 idle 态：金额可选，按钮为"确定启动"，紧急停止禁用。
- 设备详情 starting 态：金额不可选，按钮为"启动中..."，启动步骤逐步点亮。
- 设备详情 running 态：按钮为"结算"，紧急停止可用，四步全亮。
- 结算弹窗：显示消费金额与剩余余额，点击"我知道了"回到 idle 态。
- 紧急停止弹窗：红色风格，点击"我知道了"回到 idle 态。

## 验收标准

1. 四种设备页面主题色正确，与首页金刚区图标颜色对应。
2. 设备列表页卡片信息完整（图标/名称/位置/编号/状态）。
3. 设备详情页启动流程动画正常（四步依次点亮）。
4. 结算流程：启动成功 → 结算 → 弹窗 → 余额扣除 → 回到初始态。
5. 紧急停止：启动中/运行中可点击 → 弹窗 → 余额扣除 → 回到初始态。
6. `npm run typecheck` 和 `npm run build` 通过。
