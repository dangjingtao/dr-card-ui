# T045｜诗得丽专栏签到：未签"X"标记 + 补签看广告

## 状态与类型

- 状态：`Ready`
- 类型：Feature / Check-in Adjustment（签到组件改造）
- 优先级：P1
- 所属阶段：诗得丽品牌专栏施工（2026-09-09 批次）

## 当前事实与差距

- 现状（截图 2）：签到日历已签日期展示为深色圆点带 ✓；未签日期（13、14）展示为灰色椭圆带数字。
- 需求：
  - 未签日期视觉改为"X"形状（替代灰色椭圆+数字）。
  - 增加「补签」按钮入口，点击补签需要看一段广告（演示广告即可）。
- 现状卡片已有「还差 N 天」右侧链接，可作为补签入口的承载位置；本卡保留该文字链接，但补签逻辑收敛到新按钮。

## 目标

1. 未签日期视觉改为"X"形状，保持整体卡片风格（淡金色卡底 + 暖色文字）。
2. 引入补签按钮入口；点击后播放一段演示广告。
3. 演示广告播放完成后自动完成当日补签，回写签到状态。
4. 广告本身本期使用演示占位（视频缩略图 + 跳过按钮），后续接入真实广告 SDK。

## 原型范围

- 需求来源：2026-09-09 用户现场反馈 + 第二张截图。
- 节点：诗得丽专栏签到卡（`/dearseed` 首页内签到区块）。

## 不在范围

- 不接入真实广告 SDK（SDK 选型与商务未确认）。
- 不修改 7 天奖励、泡泡值增量等数值。
- 不修改已签日期的视觉。

## 实施要求

- 未签日视觉：
  - 移除椭圆+数字样式。
  - 改为半透明深色圆形 + 居中"X"字符（Lucide `x` 或等价 SVG）。
  - 已签日保持当前 ✓ 视觉。
- 补签按钮：
  - 位于卡片右上角「还差 N 天」附近（与"还差 N 天"并列或点击即触发），点击进入补签流。
  - 补签流：演示广告组件（全屏遮罩 + 视频缩略图 + 跳过/关闭按钮）。
  - 跳过不可用，必须看完（最少停留时长 5 秒）；时间到自动收起。
- 补签成功后：
  - 刷新日历，缺失日变为 ✓。
  - 减少"还差 N 天"中的 N。
- 演示广告组件需支持：
  - 至少 1 条占位视频/动图（用工程内静态资源或 mock 视频 URL）。
  - "看完即完成"判定（不依赖真实 SDK 事件）。

## 状态与交互矩阵

| 状态        | 日历视觉        | 补签按钮           | 用户操作           | 结果           |
| --------- | ----------- | --------------- | -------------- | ------------ |
| 当日未签      | 半透明圆 + "X"  | 显示「补签」按钮       | 点击补签 → 看广告 → 完成 | 该日变为 ✓      |
| 当日已签      | 暖色 ✓        | 隐藏「补签」按钮       | —              | —            |

| 补签完成       | 已补日变为 ✓     | 按钮隐藏（如本日已补）    | —              | 同步更新"还差 N 天" |
