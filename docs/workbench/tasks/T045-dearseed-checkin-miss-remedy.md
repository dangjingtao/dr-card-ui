### 签到视觉规则（最终版，PRD 多轮迭代）

| 状态 | 视觉 | 可点击 |
| --- | --- | --- |
| `today`（今天未签，state='today' 且不在 DONE_DAYS） | **矩形（rounded-md）+ 深色背景（`#3A2E1F`）+ 白色 X + 日期**（X 上 + 日期下） | 否（展示态） |

### 补签流程（最终版）

```
用户进入 /checkin 完整月历
  ↓
点 makeup 日（显示「补签」）
  ↓
DemoAdPlayer 全屏弹窗 + 5 秒倒计时（不可跳过）
  ↓
倒计时归零 → 触发 onComplete
  ↓
关闭广告 → open('make-up-success') → 弹出补签成功页
```

## 与原 PRD 的差异（已记录）

1. **未签日视觉范围** — 原 PRD：所有未签日都 X。实际：**today（今天未签）→ X + 日期；makeup（过往漏签）→「补签」两字**。upcoming 显示数字。用户 2026-09-10 反馈明确分层。
2. **形状** — 原 PRD：半透明深色圆。实际：**矩形（rounded-md）+ 深色背景**。用户要求"矩形"作为统一规范。
3. **布局** — 原 PRD 未提。实际：纵向 flex-col，**X 上 + 日期下**，与 done 单元格保持结构一致。
4. **未来日期背景** — 原 PRD 未提。实际：**去掉灰色原型底**，透明 + 灰色数字，避免视觉冗余。
5. **补签入口位置** — 原 PRD：「还差 N 天」附近按钮。实际：日历格子本身可点击（makeup 分支）。用户确认"日历格子即入口"更自然。
6. **首页 7 天卡跳转** — 原 PRD 未提。实际：取消 BottomSheet，点击卡片直接跳 `/checkin`。BottomSheet 代码保留以备恢复。
7. **Today fixture 调整** — fixture 默认 `today` 在 `CHECKIN_DONE_DAYS` 里（已签），为了让"今天未签 X"视觉可见，**将 12 从 DONE_DAYS 移除**。`CHECKIN_STATUS_TEXT` 改为「今日未签到」。Hero 区 ✓ 图标同步改为 X。
8. **状态回写** — 原 PRD："补签成功后减少还差 N 天"。实际：**fixture 未改**（demo 简化），补签成功弹窗弹出，但日历不变。真实业务接入时再做 store 化。
9. **演示广告素材** — 原 PRD：占位视频/动图。实际：用 `points-benefit-voucher.webp` 静态图 + CSS 进度条占位（无视频文件依赖）。
