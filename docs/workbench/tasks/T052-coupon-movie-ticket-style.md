# T052｜卡包卡券列表：电影票样式

## 状态与类型

- 状态：`Done`（实施完成，等用户验收）
- 类型：UI / Visual Upgrade（卡包列表视觉规范）
- 优先级：P2（卡包列表视觉优化）
- 所属阶段：卡包体验优化（2026-09-10）

## 背景

- 现状：卡包（`/card`）的卡券列表使用「顶部金色细条 + 白底卡片」样式，与卡博士品牌视觉同质化严重，缺少「卡券」专属识别度。
- 需求（2026-09-10 用户现场反馈）：用类似电影票的样式呈现每张卡券，让卡券本身具备「票」的视觉语言。
- 设计方向（用户 2026-09-10 三轮反馈迭代）：
  - 第一版：完整电影票（含票根 + COUPON 副字 + 券号 + DEAR SEED 标识）
  - 微调：去掉票根 + COUPON 改中文 + 使用/转赠按钮改为等宽并列

## 目标

1. 卡包三种状态（可用/已使用/已过期）统一使用电影票样式呈现。
2. 票面信息分层：左色块（金额/识别区）+ 右内容（券名/到期/状态/操作）。
3. 撕齿缺口 + 虚线分隔模拟真实电影票撕票效果。
4. 不破坏现有跳转逻辑（使用 → `openUseSheet` / 转赠 → `/card/share`）。

## 实施要求

### 视觉规范（最终版）

| 区域 | 元素 | 规格 |
| --- | --- | --- |
| **外层卡片** | 圆角 + 阴影 | `rounded-[16px] bg-surface shadow-sm`，`overflow-hidden`（裁掉两端 notch） |
| **撕齿缺口** | 左右两端各一个半圆 | 直径 14px，`bg-surface-inactive`，绝对定位 + `translate(-50%, -50%)` / `translate(50%, -50%)` |
| **左色块** | 背景 | 可用：`linear-gradient(135deg, var(--color-reward), var(--color-reward-strong))` 金色渐变；已用/已过期：灰色渐变 |
| **左色块** | 金额 | 有 amountLabel 时显示大金额（¥34px），无 amountLabel 时显示 Ticket 图标 |
| **左色块** | 副字 | 中文「卡券」，11px，字距 `tracking-widest`，白色 85% 透明 |
| **中间分隔** | 虚线 | `border-l border-dashed`，金色（可用）/ 灰色（已用/已过期） |
| **右内容** | 券名 | 15px 半粗，黑色（可用）/ 灰色（已用/已过期） |
| **右内容** | 状态徽标 | 右上角小 pill：可用 = `bg-reward-subtle text-reward-text`；已用 = `bg-coupon-used-bg text-coupon-used`；已过期 = `bg-surface-inactive text-text-inactive-muted` |
| **右内容** | 到期 | 日历图标 + `expireAt + 到期`，11px |
| **右内容** | 使用须知 | `limitNote`，11px（可选字段） |
| **右内容** | 操作按钮 | 两个等宽 pill（`flex-1`），无主辅关系：使用 = `bg-primary` 实心橙；转赠 = `border` 描边 |

### 三态行为矩阵

| 状态 | 左色块 | 标题色 | 状态徽标 | 使用按钮 | 转赠按钮 |
| --- | --- | --- | --- | --- | --- |
| 可用 | 金色渐变 | 黑色 | 绿色「可用」 | 橙色实心 | 灰色描边 |
| 已使用 | 灰色渐变 | 灰色 | 灰色「已使用」 | 隐藏 | 灰色禁用 |
| 已过期 | 灰色渐变 + opacity-90 | 灰色 | 灰色「已过期」 | 隐藏 | 灰色禁用 |

### 不在范围

- 不修改 Card 页 Tab、空态、底部使用说明等其他区域。
- 不修改 Card 页「使用体验券」底部 sheet（T044 已独立完成）。
- 不引入新依赖，全部使用 Tailwind + inline style 实现。
- 不实现入场动效（待后续迭代）。

## 状态与交互矩阵

| 入口 | 触发 | 效果 |
| --- | --- | --- |
| 卡包 → 可用 Tab | 展示 | 每张可用券渲染为金色色块电影票，底部两个等宽按钮 |
| 卡包 → 已使用 Tab | 展示 | 每张已用券渲染为灰色色块电影票，只显示转赠按钮（禁用） |
| 卡包 → 已过期 Tab | 展示 | 每张过期券渲染为灰色色块电影票（opacity-90），两按钮都禁用 |
| 点击使用 | 点击 | 走原 `openUseSheet(coupon)` → 弹「使用体验券」sheet |
| 点击转赠 | 点击 | 跳 `/card/share?coupon=${id}` |
