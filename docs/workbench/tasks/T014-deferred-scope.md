# T014｜暂缓、旧稿与试验范围关闭

## 状态与类型

- 状态：`Accepted`（用户于 2026-08-21 明确确认通过）
- 类型：Product / Design / Scope
- 优先级：P0

## 当前事实与差距

- 原型包含明确“暂时不做/先不做”、旧积分体系、数字空间、健康管理、颜色测试和总览画布，共 12 个非实施节点。
- 旧 T014“全量页面适配整理”会把这些页面重新混入实施范围，无法验收；现 T014 改为范围关闭卡。
- 12 节点覆盖：`#1、#3、#9、#10、#31、#45–#47、#50–#53`。
- 实施卡 T005–T013 共 60 节点 + T014 12 节点 = 72 节点，公式在 `design-assessment.md` §4 已对齐。

## 目标

对 12 个非本轮实施节点逐一形成范围结论，防止智能体因“全量还原”自行施工或删除证据。

## 实施要求

- 每个节点标记：`Exclude / Preserve Evidence / Future / Superseded / Needs Decision`。
- 说明它与当前泡泡值、会员、搭子等主线的关系。
- 路由不得误暴露暂缓功能；文档索引仍可定位原型证据。
- 禁止把 #1 总览画布实现成巨型首页。
- 不删 `不靠谱的设计历史/`；不擅自合并 #50/#51 与 #5 泡泡值明细。

## 路由 / 入口审计

- 现有 5 路由：`/`、`/card`、`/exchange`、`/profile`、`/draw-success`，与 12 暂缓节点无对应。
- 底部导航 4 Tab（首页 / 卡包 / 兑换 / 我的）未指向任何暂缓节点。
- `src/` 全量 `Link / to= / href=` 扫描未命中 12 节点对应路径。
- 结论：12 节点在当前代码中无独立路由、无导航入口、无客户端可达路径。
- 详细审计：见 `decisions/T014-scope-closure.md` §4。
