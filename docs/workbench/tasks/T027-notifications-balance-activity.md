# T027｜消息通知：余额不足与校内外活动

## 状态与类型

- 状态：`Done`
- 类型：Feature / Notification
- 优先级：P0（通知余额不足）

## 当前事实与差距

- 当前 APP 已有消息通知功能（推送设置、消息提醒），但缺少余额不足通知和校内外活动通知。
- 会议讨论：
  - 校内外活动通知：后台暂无，暂不能实现。
  - 余额不足通知：需问黄朝确认后端能力与接口。

## 目标

1. 余额不足通知：用户账户余额低于阈值时推送通知。
2. 校内外活动通知：待后台就绪后接入。

## 原型范围

- 需求来源：`卡博士APP缺失及新增功能.xlsx` Sheet1「通知」P0 + 2026-08-31 会议笔记。

## 不在范围

- 不做校内外活动通知的后台实现（仅当前端展示，待后台就绪）。
- 不修改已有消息通知设置页。

## 实施要求

- 余额不足通知：在消息列表中以系统通知类型展示，可点击查看详情。
- 校内外活动通知：预留通知类型分类（全部/未读/系统/活动），后台就绪后接入。
- 复用现有通知列表（`/notifications`）和消息详情（`/notifications/:id`）页面。

## 状态与交互矩阵

- 余额不足通知消息项展示。
- 点击通知进入详情页。
- 活动通知占位态（后台未就绪时的提示）。

## 验收标准

- 余额不足通知可正常推送和查看。
- 通知列表正确分类展示不同类型的通知。
