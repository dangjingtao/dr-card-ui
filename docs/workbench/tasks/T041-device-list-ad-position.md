# T041｜设备列表页广告位插入策略

## 状态与类型

- 状态：`Done`
- 类型：UI / Feature / Monetization
- 优先级：P1

## 背景与历史

- 2026-09-07 决策：卡博士 APP 加入广告运营，设备列表页在「第 2、3 个设备中间」插入与设备卡片等高的广告位，且设备数量 < 3 时不展示。
- 2026-09-08 决策：放宽小数量场景的不展示策略，广告位始终可见，仅位置随设备数量动态调整：
  - 设备数量 ≥ 3：广告位插入到第 2 与第 3 个设备之间。
  - 设备数量 < 3（0、1、2 个设备）：广告位直接展示在列表末尾。
- 同步覆盖：四类设备列表页（淋浴/洗烘/饮水/吹风）以及「我的-常用设备」「我的-收藏设备」两个内嵌列表区块。

## 目标

1. 在设备列表场景下保证广告位始终曝光，仅调整插入位置。
2. 视觉上与设备卡片等高、有清晰「广告」标识，避免误点击。
3. 不改变现有设备卡片结构、底部固定扫码按钮、扫码启动底部面板。

## 改动范围

| 文件 | 变更 |
| --- | --- |
| `src/app/fixtures/device.ts` | 淋浴设备列表扩到 4 个；洗烘/饮水/吹风保留现状或调整为 1 个；为广告位定义主题色配置 |
| `src/components/mobile/AdBannerSlot.tsx` | 新增：与设备卡片等高的广告位组件（含「广告」角标、关闭可选） |
| `src/components/mobile/DeviceListWithAd.tsx` | 新增：封装「按规则插入广告位」的列表渲染逻辑（≥3 插中间、<3 末尾） |
| `src/pages/DeviceListPage.tsx` | 把设备列表渲染替换为 `DeviceListWithAd` |
| `src/pages/legacy/DeviceListSimplePage.tsx` | 同样接入 `DeviceListWithAd`，覆盖常用设备 / 收藏设备两个区块 |
| `src/app/router/index.tsx` | 不变 |
| `src/styles/card-doctor-theme.css` | 新增 `--ad-banner-*` 主题变量 |

## 验收标准

1. 设备列表页（4 类设备）：
  - 淋浴列表展示 4 个设备时，广告位出现在第 2 与第 3 之间。
  - 吹风/洗烘/饮水列表设备 < 3 时，广告位出现在列表末尾。
2. 「我的-常用设备」「我的-收藏设备」：均按同一规则展示广告位。
3. 广告位视觉：
  - 高度与设备卡片一致。
  - 左上角带「广告」角标（`bg-yellow-100 text-yellow-700`）。
  - 背景使用浅色渐变，与设备卡片形成可识别差异。
4. 不影响底部固定扫码按钮、扫码启动底部面板。
5. `npm run typecheck` 通过。

## 必交证据

- 设备列表页截图：淋浴（4 设备 + 中间广告）、吹风（1 设备 + 末尾广告）。
- 「我的-常用设备」截图：≥3 时中间广告、<3 时末尾广告。
- `npm run typecheck` 结果。

## 不在范围

- 广告内容来源 / 后端接口 / 曝光埋点（仅做 UI 占位与策略）。
- 设备列表底部固定扫码按钮、扫码启动面板的交互改动。
- 新建设备类型 / 设备图标。
