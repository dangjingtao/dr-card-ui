# T033｜卡博士APP首页

## 状态与类型

- 状态：`Done`

- 类型：UI / Shell / Homepage

- 优先级：P0

## 当前事实与差距

- `/legacy-home` 已有基础壳实现（`src/pages/LegacyHome.tsx`），包含：搜索栏、头像入口、Banner 轮播、四宫格快捷入口（淋浴/洗烘/饮水/吹风）、扫一扫入口、三张列表卡片（诗得丽品牌专栏 / 公益板块 / 卡博士品牌故事）、福袋悬浮按钮、三项底部导航（首页 / 服务 / 我的）。

- 诗得丽品牌专栏入口已修复，点击跳 `/dearseed`（独立专栏页）。

- 头像点击跳 `/membership`（会员中心），但该入口在卡博士APP语境下是否合理待确认。

- 四宫格快捷入口（淋浴/洗烘/饮水/吹风）当前纯展示，无点击交互，应跳转到设备服务页或对应功能。

- 公益板块、卡博士品牌故事两张卡片当前无 `to` 目标，纯展示占位，需要确认是否有独立页面。

- 福袋悬浮按钮跳 `/redeem`（兑换码页），该链路是否符合卡博士APP语义待确认。

- 底部导航「服务」「我的」两项当前无实际路由，仅视觉展示。

- Banner 轮播内容当前复用诗得丽专栏的签到 Banner，不符合卡博士APP定位。

- 首页整体视觉风格沿用诗得丽金橙体系，卡博士APP是否需要独立品牌色待确认。

## 目标

1. 完善卡博士APP首页，使其成为完整、可交互的主入口。
2. 明确首页各入口的去向，打通首页 → 二级页的导航链路。
3. 调整 Banner 内容为卡博士APP相关（设备服务、优惠活动等）。
4. 确认卡博士APP的视觉基调（是否复用现有金橙 Token 或调整）。

- 需求来源：当前 `/legacy-home` 已有结构 + 「不靠谱的设计历史」中参考首页设计（仅作参考，不直接照搬）。

## 实施要求

- 首页所有可交互入口必须有明确的点击目标或状态反馈，不能有假按钮。

- Banner 轮播内容替换为卡博士APP相关主题（设备服务、优惠活动等）。

- 快捷入口宫格点击后跳转到设备服务页（`/legacy-service`，T034 承载）。

- 头像入口跳转到卡博士个人中心（`/legacy-profile`，T035 承载）。

- 扫一扫入口跳 `/legacy-home/scan`（现有页面）。

- 诗得丽品牌专栏入口跳 `/dearseed`（已有独立专栏页）。

- 底部导航「服务」跳设备服务页（T034），「我的」跳个人中心（T035）。

- 公益板块、卡博士品牌故事两张卡片若无需独立页，则保持纯展示但需明确标注。

- 页面使用三项底部导航（`LEGACY_TAB_ITEMS`），与主入口五项 TabBar 分离。
