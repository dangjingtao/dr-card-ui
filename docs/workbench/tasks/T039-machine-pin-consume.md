# T039｜设置消费密码（双状态 + 修改/删除）

## 状态与类型

- 状态：`Doing`

- 类型：Feature / UI

- 优先级：P2

## 当前事实与差距

- 卡博士 APP 让学生"设置/修改/删除自己的消费密码"（2026-09-07 用户决定）。
- 消费密码分为两种状态：**未设置** / **已设置**，对应不同流程入口。
- 「我的」页宫格已有「消费密码」入口（KeyRound 图标，紧跟收藏设备之后），指向 `/legacy-profile/machine-pin`。
- 既有 `userInfoStore.pin` 字段（mock 默认 `000000`）。

## 目标

1. 同一页内部根据用户当前是否设置过密码，调度两条不同的流程：
   - **未设置** →「请设置消费密码」二步式流程（输入 → 二次确认 → 写入 → 成功弹窗）。
   - **已设置** →「请输入消费密码」验证页 → 校验通过 →「消费密码管理」功能选择页 → 修改 / 删除。
2. 修改走同样的二步式设密流程，但顶部标题改为「"修改消费密码」」；删除直接清空 `userInfo.pin` 并弹"已删除"成功弹窗。
3. 右下角加"原型状态切换"按钮，支持"未设置 / 已设置"演示态切换；切换时清空残留输入。

## 原型范围

- 顶部：金色渐变 + 标题随 phase 切换：
  - `set` → 「请设置消费密码」
  - `verify` → 「请输入消费密码」
  - `menu` → 「消费密码管理」
  - `change` → 「修改消费密码」
  - `delete` → 「确认删除」
- 当前状态卡（除 `delete` 外）：「当前消费密码：`00****`」首尾掩码 / 未设置时显示「未设置」。
- 步骤说明卡（浅金背景）：根据 phase 切换提示文案。
- **verify 阶段**：6 格方框 + 「确认」按钮（金渐变）。
- **menu 阶段**：白底圆角横条两张（修改 + 删除），左侧图标色块（修改金底、删除红底），右侧 chevron。
- **set / change 阶段**：步骤指示器 ① 输入密码 → ② 确认密码 + 6 格方框（两次输入 + 「下一步」/「确认保存」金渐变按钮 + 「返回上一步」灰字链接）。
- **delete 阶段**：红底图标 +「确认删除消费密码？」+「取消」/「确认删除」（红底按钮）。
- 成功弹窗：根据 phase 显示「设置成功」/「修改成功」/「已删除」三种文案；底部「继续操作」/「返回我的」两按钮。
- 右下角浮动演示按钮：「未设置密码」/「已设置密码」（FlaskConical 图标）。

## 不在范围

- 不做忘记密码 / 旧密码校验失败次数限制 / 锁定。
- 不做修改与重置分离（直接覆盖 `userInfo.pin`）。
- 不做密码强度规则。
- 删除后 pin 字段清空 `''`（下次进入走"未设置"流程）。

## 实施要求

#### ConsumePinPage（重写，`/legacy-profile/machine-pin`）

- 内部 `phase` state：`set | verify | menu | change | delete`。
- 顶部标题与提示卡根据 `phase` 切换文案。
- **演示态**（sessionStorage `KBS_CONSUME_PIN_DEMO`，值 `unset | set`）：
  - 默认 `set`（因为 `userInfo.pin = '000000'`）。
  - 右下角按钮点击切换：清空所有输入 + 切到对应 phase 入口（`unset` → `set`，`set` → `verify`）。
- **verify 阶段**：6 格方框 + 校验 `userInfo.pin` → 校验通过跳 `menu`；校验失败红字。
- **menu 阶段**：两个白底圆角横条（修改 / 删除），点击进入 `change` 或 `delete`。
- **set / change 阶段**：复用同一 `PinSteps` 子组件（二步式，6 格方框），通过 props 决定是「下一步 / 确认保存」+ 顶部标题文案。
- **delete 阶段**：红底图标卡片 +「取消」/「确认删除」按钮，点击「确认删除」mock 600ms → 清空 pin → 弹"已删除"成功弹窗。
- **成功弹窗**：根据 `phase` 显示「设置成功 / 修改成功 / 已删除」三种文案；「继续操作」智能跳转（修改/设置完成 → verify；删除完成 → set），「返回我的」直接离开。

#### 路由 + 入口

- `/legacy-profile/machine-pin` 路由不变；「我的」宫格 `KeyRound` 入口不变。
- `routes.ts` owner 更新为「设置消费密码页（双状态 + 修改/删除）」。

## 状态与交互矩阵

- **ConsumePinPage phase = set**：步骤 1 / 步骤 2 / 加载 / 成功 / 错误反馈。
- **ConsumePinPage phase = verify**：输入 / 校验失败红字 / 校验通过跳转。
- **ConsumePinPage phase = menu**：进入修改 / 进入删除 / 返回我的。
- **ConsumePinPage phase = change**：步骤 1 / 步骤 2 / 一致性失败红字 / 加载 / 成功 / 返回 menu。
- **ConsumePinPage phase = delete**：取消 / 加载 / 成功 / 返回 menu。
- **演示态切换按钮**：未设置 ↔ 已设置。

## 验收标准

- 入口可达：`/legacy-profile/machine-pin` 在 dev server 返回 200。
- 「我的」宫格「消费密码」入口点击跳转该路由。
- **未设置态**（mock 演示按钮切到「未设置密码」）：进入页面即看到「请设置消费密码」二步式流程；正确填写后写入并弹「设置成功」。
- **已设置态**（默认）：进入页面看到「请输入消费密码」；正确输入 `000000` 后跳「消费密码管理」功能选择页。
- **修改路径**：点击修改 → 进入「修改消费密码」二步式流程；完成后弹「修改成功」。
- **删除路径**：点击删除 → 进入「确认删除」页 → 确认 → 清空 pin + 弹「已删除」。
- **演示态切换按钮**：右下角浮动 + 点击后清空残留输入并切到对应 phase 入口。
- 返回按钮：根据 phase 切换正确返回（set/verify → 上一页；menu/change → verify；delete → menu）。
