## 实施要求

### 弹窗触发

- 进入 `/dearseed` 页面 → `useEffect` 自动弹身份选择器
- 本会话内仅首次进入时触发（`sessionStorage.dearseed_picker_shown` 标记）
- URL 带 `?picker=off` 时跳过（演示态可关闭）
- URL 带其他 `?overlay=*`（如 reminder）时跳过，避免覆盖其他演示态

### 三级弹窗流程

```
进入 /dearseed
  │
  ▼
IdentityPickerSheet（身份选择）
  │
  ├─「诗得丽新增用户」→ NewcomerCouponDialog（洗发水体验券）
  │     └─ 领取成功 → /exchange
  │
  └─「卡博士存量用户」→ NewcomerGiftSheet（新人礼包占位）
        └─ 了解卡博士新人礼包 → /mall
```

### 身份选择弹窗规范（IdentityPickerSheet）

- 顶部 DEAR SEED 眉标
- 标题：「请选择身份」
- 副标题：「Demo 演示用，请选择你希望模拟的用户身份。」
- 两个并排卡片按钮：
  - 卡博士存量用户（`Gift` 图标 + 暖色背景 + "已有卡博士账户，享受新人礼包"）
  - 诗得丽新增用户（`Crown` 图标 + 会员卡色背景 + "诗得丽关爱机项目用户，享受洗发水体验券"）
- 关闭按钮照常

### 新人礼包弹窗规范（NewcomerGiftSheet）

- 顶部条形 tag：「演示位 · 后续接入」（金色边框 + 暖色背景）
- 标题：「新人礼包（占位）」
- 副标题：「卡博士存量用户新人礼包，正式券种由丁总确认后接入。」
- 图标：`Gift` Lucide 图标（礼盒，贴合"礼包"语义）
- 主按钮文案：`了解卡博士新人礼包` → 跳 `/mall`
- 不修改原洗发水体验券弹窗的视觉、字段、核销链路。
