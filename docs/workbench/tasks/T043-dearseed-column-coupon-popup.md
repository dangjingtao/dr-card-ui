# T043｜诗得丽专栏入口卡券弹窗：用户区分与占位券

## 状态与类型

- 状态：`Ready`
- 类型：Feature / Coupon Popup（品牌专栏卡券）
- 优先级：P0（专栏入口核心转化路径）
- 所属阶段：诗得丽品牌专栏施工（2026-09-09 批次）

## 当前事实与差距

- 用户进入诗得丽品牌专栏时，目前只弹出"洗发水体验券"一种卡券。
- 业务要求按用户身份区分券种：
  - **诗得丽关爱机项目用户**：弹出当前已有的洗发水体验券（保持不变）。
  - **卡博士存量用户**（即不属于关爱机项目）：弹出"其他的兑换券"，具体券种未定，先留演示位置。

## 目标

1. 用户身份识别后弹出对应券种：
   - 关爱机用户：洗发水体验券（现有逻辑）。
   - 卡博士存量用户：占位券（演示位置）。
2. 占位券需具备演示态能力，可由后续接入真实券种替换。
3. 弹窗触发位置与现有"进入品牌专栏"流程一致，不新增入口。

## 原型范围

- 需求来源：2026-09-09 用户现场反馈。
- 参考节点：
  - 现状弹窗：洗发水体验券弹窗（已实现于品牌专栏入口）。
  - 占位券：暂无原型，先以"通用兑换券占位卡"样式呈现。

## 不在范围

- 不确定占位券的具体券种（洗发水/沐浴露/吹风等），本期只做演示位。
- 不修改卡博士 APP 主入口流程；本卡只影响诗得丽专栏入口。
- 不实现后端用户身份判定接口（mock 即可，按 isDearseedCare 之类的本地标记）。

## 实施要求

- 在专栏入口弹窗逻辑中插入用户身份分支：
  - 命中"关爱机用户"分支 → 现有洗发水体验券弹窗。
  - 命中"其他用户"分支 → 新的占位券弹窗。
- 占位券演示态视觉规范：
  - 顶部条形 tag：「演示位 · 后续接入」
  - 标题：「通用兑换券（占位）」
  - 副标题：「正式券种由丁总确认后接入」
  - 图标：复用现有 `coupon` 类图标或 Lucide `ticket`。
  - 主按钮文案：`了解卡博士存量用户专属兑换` → 跳转至当前 `/mall` 或占位详情页（与丁总确认后切换）。
- 不修改原洗发水体验券弹窗的视觉、字段、核销链路。

## 状态与交互矩阵

| 触发           | 身份识别           | 弹窗内容         | 用户操作                  |
| ------------ | -------------- | ------------ | --------------------- |
| 进入 `/dearseed` | 关爱机用户          | 洗发水体验券弹窗（现有） | 使用 / 关闭按钮（沿用）         |
| 进入 `/dearseed` | 卡博士存量用户        | 占位券弹窗（新）     | 「了解卡博士存量用户专属兑换」/ 关闭 |

## 验收标准

- 两种身份进入专栏看到不同弹窗，互不影响。
- 占位券视觉带"演示位"标签，醒目但不刺眼。
- 关闭弹窗后页面动线与原版一致。
- `npm run typecheck` / `npm run build` 通过。
- 375×812 实现截图与原型/说明对照，差异在卡内记录。
