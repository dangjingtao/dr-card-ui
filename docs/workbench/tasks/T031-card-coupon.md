# T031｜积分卡券与优惠券

## 状态与类型

- 状态：`Done`（2026-09-08 提交 `4afa0e4` 推送至 `preview`：优惠券前端落地 + 卡详情页红色解绑 pill + 文案二次确认弹窗 + `unbindCard` 仅移除卡列表保留记录；B-047 积分卡券范围与 B-048 优惠券接口仍维持待定，但当前 UI 范围已交付并可验收）

- 类型：Feature / UI

- 优先级：P0（积分卡券、优惠券）

## 当前事实与差距

- 当前 APP 未展示积分卡券（实体卡）和优惠券信息。

- 会议讨论：

  - 积分卡券：包含实体卡和优惠卡券，实体卡展示已绑定的实体卡数量及具体信息（图标、卡名称、卡号、卡状态、卡详情）。

  - 优惠卡券：展示个人拥有的优惠券数量及具体信息。

  - 积分卡券倾向做，但需要丁总最终确认（「我再找找，倾向做，丁总确认」）。

  - 优惠券（补助）：支持查看功能。

## 目标

1. 积分卡券页：展示已绑定实体卡及优惠卡券信息。
2. 优惠券（补助）查看：展示已拥有的优惠券列表和详情。
3. 待丁总确认积分卡券的最终范围。

## 原型范围

- 需求来源：`卡博士APP缺失及新增功能.xlsx` Sheet1「积分卡券」「优惠卡券」「优惠券」P0 + 2026-08-31 会议笔记。

## 不在范围

- 不做实体卡绑定/解绑流程（仅展示已绑信息）。

- 不做优惠券的领取和使用闭环（仅查看和展示）。

## 实施要求

- 积分卡券页：顶部 Tab 区分「实体卡」和「优惠卡券」。

- 实体卡列表：展示卡片图标、卡名称、卡号、卡状态（可用/已使用/已过期）。

- 优惠卡券列表：展示优惠券名称、面额、有效期、使用条件。

- 优惠券（补助）查看：在「我的」页面或卡券中心展示，可查看全部优惠券信息。

- 实体卡解绑（2026-09-08 新增）：卡详情页顶部右侧红色"解绑"pill → 文案二次确认弹窗（无密码） → 调用 `unbindCard(id)` 从卡列表移除 → `KBS_CARD_DEMO_STATE` 切为 `unbound` → 跳回 `/legacy-profile/my-cards` 列表空态；历史充值/退款记录在 `recordsActions` 中保留，不随卡删除。

- 数据先用夹具占位，待接口确认后替换。

## 状态与交互矩阵

- 积分卡券入口默认态。

- 实体卡列表（可用/已使用/已过期三态）。

- 优惠卡券列表（可用/已使用/已过期三态）。

- 实体卡详情页。

- 优惠券详情页。

- 空态（无卡券时展示）。
