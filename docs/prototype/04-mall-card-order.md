## 1. 洗护兑换专区

> ✅ **视觉方向已确认（2026-08-24）**：用户提供的新界面作为风格参考，确认采用暖白背景、顶部轻量泡泡值、「全部 / 洗发水 / 护发素 / 头皮护理」四分类胶囊 Tab、三列商品卡、深色兑换按钮和底部提示。历史 T11 的深绿渐变与私有色不再采用，并使用 Com Design 语义 Token 实现。

### 页面定位
诗得丽泡泡值兑换的商品列表页。

### 页面内容
- 搜索框。
- 分类 Tab：全部、洗发水、护发素、头皮护理（2026-08-24 用户参考图确认）。
- 原型中的综合、兑换量、泡泡值排序状态继续保留为调试/直达状态，不占用当前前台 Tab。
- 展示放入洗护关爱机的 SKU。
- 商品卡片包含商品名、所需泡泡值、兑换量等，例如「DearSeed 洗发水样包 / 200🫧 / 兑换量 2000+」。

### 主要交互
- 全部 → 展示完整商品列表。
- 洗发水 / 护发素 / 头皮护理 → 按分类过滤商品。
- 点击商品 → 商品兑换弹窗。

## 2. 兑换量排行 / 泡泡值排行

### 页面定位
洗护兑换专区的排序状态，而不是独立业务模块。

### 页面内容
沿用兑换专区商品列表，只改变排序维度和选中状态。

### 主要交互
可在综合 / 兑换量 / 泡泡值之间切换，点击商品继续进入兑换弹窗。

## 3. 商品兑换弹窗

### 页面定位
用户确认用泡泡值兑换样包的确认层。

### 页面内容
- 商品图与商品名。
- 数量示例 `x1`。
- 商品说明。
- 所需泡泡值。
- 「立即兑换」。

### 主要交互
确认兑换 → 存入卡包成功状态。

## 8. 卡包

### 页面定位

### 页面内容
- 顶部标题「我的卡包」。
- 右上角「使用记录」。

- 卡券列表展示：商品图、卡券名、简介、有效期、状态。

### 页面状态

- 卡包 - 可用。
- 卡包 - 已使用。
- 卡包 - 已过期。

### 主要交互
- 使用记录 → 订单管理（原型当前链接到订单管理）。
- 使用 → 核销。
- 转赠 → 分享。
- 返回 → 我的。

## 11. 兑换卡券 / 兑换成功

> ⚠️ **最高风险待确认｜历史设计 T12**：历史稿把规则定死为 `^[A-Za-z0-9]{12}$`，即 12 位字母数字；但摹客现有状态分别出现“8 位兑换码”和“11 位兑换码”。**12 位规则不得沿用。施工前必须先确认兑换码长度、字符集、错误态和成功态。**

### 页面定位
通过兑换码获取卡券。

### 页面内容
- 兑换码输入框。
- 「确认兑换」。

### 主要交互
确认兑换 → 兑换成功状态。

### 成功状态
提示兑换成功并已存入卡包，提供「查看我的卡包」。

### 原型差异
输入提示在两张原型中分别出现「请输入 8 位兑换码」与「请输入 11 位兑换码」。此处只记录差异，不自行决定真实位数。

## 13. 添加新地址

### 页面内容

## 14. 订单管理

### 页面定位
用户查看商城订单状态。

### 页面内容
Tab：全部订单 / 已完成 / 进行中 / 售后中。

订单卡片示例包含：
- 配送状态；
- 商品名和规格；
- 单价与数量；
- 下单时间；
- 商品件数与实付款。

### 主要交互
订单项 → 订单详情。

---

## 15. 订单详情

### 页面定位
查看单笔商城订单的完整信息。

### 页面内容
- 订单状态，例如已收货。
- 商品信息与数量。
- 收货地址、联系人和脱敏手机号。
- 价格信息：商品总价、运费、实付款。
- 订单信息：订单编号、下单时间。

### 主要交互
返回 → 订单管理；原型保留客服入口。
