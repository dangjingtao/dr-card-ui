# 卡博士 APP

本仓库已经从「卡博士移动 APP 高保真 UI」进入正式开发阶段。它同时承载 UI 真相、开发集成、测试验收与生产发布；视觉与交互仍以已确认原型和 `preview` 分支为事实源，不因工程接入而随意漂移。

## 分支节奏

长期分支固定为：

```text
preview → dev → test → prod
```

- `preview`：UI 真相、视觉施工与预览验收
- `dev`：业务开发、API / JSBridge / 设备能力等工程集成
- `test`：联调、回归、测试与业务验收
- `prod`：生产发布真相源

正常晋级只走相邻方向，并原则上通过 Pull Request 完成。历史 `main` 暂时保留为旧入口与历史基线，不再承担新的开发或发布职责。

详细规则见 [分支与发布节奏](./docs/workflow/branch-strategy.md)。
