# 卡博士 APP UI

本项目用于设计与沉淀「卡博士」APP 的高保真 UI，覆盖核心页面、交互状态与视觉规范，为产品评审和后续开发提供清晰的设计参考。

## 设计文档

完整设计说明见 [设计文档.md](./设计文档.md)。如文档未覆盖细节，或文档与页面呈现存在差异，请以 Mockplus（摹客）原型为准。

## 设计历史参考

项目内的 [不靠谱的设计历史](./不靠谱的设计历史) 是从外部整理带入的历史设计资料，供后续智能体和协作者参考。该目录中的部分 UI 已经过确认，部分 UI 在后续迭代中可能被改坏或与当前结论不一致；本次先按原样完整收录，不将其视为当前实现规范。遇到冲突时，以已确认的当前原型、页面实现和设计文档为准，并注明具体依据。

## 任务工作台

项目按 72 个 Mockplus 页面节点重新评估并拆分为 15 张主任务卡，见 [实际评估与任务卡](./docs/workbench/design-assessment.md)。智能体自审通过不等于项目验收通过，最终状态以用户验收为准。
